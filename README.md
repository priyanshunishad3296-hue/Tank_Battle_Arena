# Tank Battle Arena

A 2D turn-based artillery game inspired by the classic Pocket Tanks, developed in C using the Raylib graphics library.

## Overview

Tank Battle Arena is a two-player strategy game where players take turns moving their tanks, adjusting firing angle and power, selecting weapons, and destroying the opponent using realistic projectile physics.

## Features

- Turn-based gameplay
- Dynamic terrain generation
- Tank color selection
- Weapon selection system
- Projectile physics
- Explosion animation
- Health system
- Tank movement with limited moves
- Adjustable firing angle
- Adjustable firing power
- Background music
- Fire and explosion sound effects
- Interactive game interface

## Technologies Used

- C Programming
- Raylib
- Raymath
- GCC Compiler
- Visual Studio Code
- MSYS2 UCRT64

## Controls

### Player 1

| Key | Action |
|------|--------|
| A | Move Left |
| D | Move Right |
| W | Increase Angle |
| S | Decrease Angle |
| Q | Decrease Power |
| E | Increase Power |
| Space | Fire |

### Player 2

| Key | Action |
|------|--------|
| Left Arrow | Move Left |
| Right Arrow | Move Right |
| Up Arrow | Increase Angle |
| Down Arrow | Decrease Angle |
| L | Decrease Power |
| O | Increase Power |
| Space | Fire |

## Game Flow

1. Start Game
2. Select Tank Color
3. Choose Weapons
4. Battle Begins
5. Destroy Opponent's Tank
6. Win the Match
